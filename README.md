##  Используемые инструменты
* **Зарубежный бот:** Gemini (Google)

##  Сценарии тестирования (Кейсы)

### Кейс №1: Диагностика насоса ЦНС
**Проблема:** Пониженное давление, перегрев корпуса, повышенная вибрация.
**Задача:** Получить пошаговый алгоритм диагностики и выявить причины неисправности.

### Кейс №2: Промышленная безопасность (ПБ)
**Проблема:** Обнаружение задымления на подземной электроподстанции.
**Задача:** Сформировать чек-лист действий и текст аварийного оповещения.

---

##  Результаты сравнения (кратко)

| Критерий | Яндекс Алиса (YandexGPT) | Gemini (Google) |
| :--- | :--- | :--- |
| **Техническая точность** | **Высокая:** дает конкретные допуски (0,1 мм) и цифры. | **Средняя:** описывает общие принципы. |
| **Знание стандартов** | **Отлично:** ссылается на ГОСТы и нормы РФ. | **Слабо:** использует общие инженерные подходы. |
| **Безопасность** | Дает общие рекомендации по СИЗ. | **Критически точно:** указано использование самоспасателя. |
| **Физика процессов** | Хорошо, но с избытком "воды" в тексте. | **Отлично:** четкая связь кавитации и падения КПД. |

---

##  Основные выводы

1.  **Для инженерной документации:** Яндекс Алиса предпочтительнее, так как она обучена на российской нормативной базе (ГОСТ) и предоставляет конкретные технические параметры, необходимые для заполнения техкарт.
2.  **Для оперативного реагирования:** Gemini показал лучший результат в вопросах безопасности персонала, выделив критически важное действие (включение в самоспасатель), которое Алиса пропустила.
3.  **Общий итог:** На текущий момент оптимальным является комбинированное использование: Gemini для быстрого поиска физических причин поломки и оценки рисков, Алиса — для оформления отчетности по стандартам РФ.
